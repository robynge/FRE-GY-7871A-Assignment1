# AI use disclosure

**Tools used:** OpenAI Codex for the first phase (ARK holdings only), including bounded subagents for specific code and review tasks; Claude Code with Claude Fable 5.1 for the second phase (the Nasdaq-100 comparison, the risk-factor-section analysis and the final report), including two independent review passes by Claude subagents. The configured EdgarTools MCP was used to test SEC connectivity. Data acquisition used SEC EDGAR and Yahoo Finance through reproducible Python code.

**What I used them for:** Codex inspected the course starter repository, obtained public data, corrected parsing and point-in-time data handling, implemented dictionary scoring and event windows, wrote and ran tests and regressions, and generated the notebook and an ARK-only report. Claude Code then added the Nasdaq-100 constituents to the universe, downloaded their filings with the same scripts, reran every exhibit by group, wrote the code that locates Item 1A and classifies how a quarterly report discloses its risk factors, the decomposition of a word-share change into a language and a composition term, the difference tests against QQQ holdings and the corrected-trend tests, the figures, the data workbook, and the six-page report with its separate appendix that replaces the earlier reports. Results are computed from downloaded filings and prices, not invented by the model.

**What I wrote myself:** The student supplied the assignment, the holdings sources and the starter repository, chose the sample rules (the 9 September 2026 holdings snapshot, the extension of the window to September 2026 for both groups), raised the problem that motivates the second phase (a company that replaces its risk factors with a reference to the annual report lowers its uncertainty score without a change in tone, first seen in Coinbase, 10x Genomics, Absci and SoFi), required that every result be tied to stock returns, rejected three earlier drafts of the report, and set its structure and language standard: one report of at most six pages built on the assignment's Tables 1 to 6 and Figure 1, describing the ARK holdings alone, with the QQQ comparison confined to one section and no result pooling the two portfolios; every result shown on the whole filing and again excluding Item 1A; methods and supplementary exhibits in a separate appendix. The analysis code and report text were generated with AI assistance; this disclosure makes no claim that the student independently wrote, rewrote or manually verified them. The student remains responsible for understanding every submitted line.

**Anything the model got wrong that I had to correct:** In the first phase, the model initially overlooked the existing EDGAR identity configuration. Code review also caught an event-calendar implementation that would drop missing benchmark dates and a history filter that prematurely required day +63; both were corrected and regression-tested. Review identified that treating negative year flags as active dictionary membership had retained ten removed negative words; the active-word rule corrects that mistake.

In the second phase, the Item 1A locator went through several corrections before its output was trusted: it first accepted table-of-contents entries and cross-references as the section heading, truncated one company's section at the words "Signature Bank" because of a case-insensitive signature marker, mishandled headings written with an em-dash and page-number fillers in a cross-reference index, and a fallback that accepted a bare "Risk Factors" heading returned wrong spans for two large filers and was removed in favour of reporting the section as not located. A regression on a disclosure switch observed once in annual reports returned p = 0.0000 and was replaced by a rule that reports indicators identified by fewer than ten filings as not estimable. The decomposition's language term was at first read as a change in how companies write; it partly reflects the fact that the one-sentence pointer that replaces the risk factors is itself dense in uncertainty words, so the report now relies on the change in the filing excluding Item 1A. Two review passes by Claude subagents, run at the student's request, found 26 and then 14 defects in the drafts: exhibits that described different subsamples under one heading, a table note that misdescribed the pooled sample, a sample count that differed across exhibits because the section statistics were computed before the one-filing-per-quarter filter, a hard-coded company count and a hard-coded interval width in two captions that were wrong, two figures whose colour conventions contradicted the rest, a sentence calling a difference insignificant that a table showed at p = 0.031, and a conclusion that stated an association the underlying regression supports only at p = 0.089. All were corrected in the code that generates the report, every number in the prose is read from the CSV that produced it, and all numbers spot-checked in the second pass matched. The model also framed a draft around the pooled sample of ARK and QQQ holdings and kept two superseded reports in the repository; the student rejected both choices, and the report was rebuilt on the ARK sample alone with the comparison in one section and the superseded reports removed. Passing tests and review are not represented as proof of complete assignment compliance.
